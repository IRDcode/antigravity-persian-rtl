Architecture & Safety Controls

Inline-Code-Aware BiDi + Restore

Clean-room DOM text walker skips leading <code>, <pre>, .font-mono, URLs, and relative file paths, locks unicode-bidi: isolate on managed blocks, and preserves original dir attributes so Alt+R reverts cleanly.

Strict 127.0.0.1 Guard & v2.32+ BaseWindow

Supports both legacy win.webContents and Antigravity v2.32+ BaseWindow (hubContents), strictly enforces ^https?://127\.0\.0\.1:\d+ on injection & config writes, and strips GitHub telemetry.

Auto-Repatch Windows Launcher

Launch-Antigravity-RTL.bat verifies app.asar on every launch and automatically re-applies RTL after official Antigravity updates.

Exact Backup & Strip Fallback

Restore-Antigravity-Original.bat restores byte-identical app.asar.bak (SHA-256 verified) or cleanly strips injected code even if .bak was deleted.

npm install --omit=dev
npm run doctor    # Non-destructive check
npm run patch     # Apply hardened RTL patch
npm run restore   # Revert cleanly to original app.asar

Frequently Asked Questions / سوالات متداول

Does the RTL patch disappear when Google Antigravity Desktop updates?

Official Antigravity updates replace resources/app.asar. Launching through Launch-Antigravity-RTL.bat checks dist/utils.js integrity first and automatically re-applies the hardened RTL patch whenever an official update overwrote it.

Does Antigravity Persian RTL make network calls or collect telemetry?

No. Vazirmatn-Variable.woff2 is bundled inside app.asar, GitHub update polls and shell.openExternal calls are removed, config writes to ~/.antigravity-rtl.json are sanitized, and injection runs strictly on http(s)://127.0.0.1 origins.

How do I revert Antigravity Desktop back to the original unpatched app?

Run Restore-Antigravity-Original.bat (or npm run restore). It restores the byte-identical app.asar.bak backup with SHA-256 verification, or strips the injected block and offline font automatically via strip_fallback even if the backup file was deleted.
